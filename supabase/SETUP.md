# إعداد Supabase لموقع Sakeena

## 1. إعداد قاعدة البيانات وتسجيل الدخول

1. أنشئ مشروعًا جديدًا في حسابك على Supabase وسمّه `Sakeena` (الاسم الظاهر فقط؛ Supabase ينشئ رابطًا ومفتاحًا خاصين بالمشروع).
2. شغّل ملفات `migrations/` بترتيب أسمائها، بما فيها `20261113000000_profiles.sql` و`20261125000000_properties_appointments.sql`، من SQL Editor أو باستخدام Supabase CLI.
3. من إعدادات المشروع، ضع **Project URL** و**Publishable key** (أو المفتاح العام `anon`) في `supabase-config.js`. لا تضع `service_role` أو أي مفتاح سري في هذا الملف.
4. فعّل تأكيد البريد الإلكتروني واضبط SMTP في Supabase قبل استخدام التسجيل خارج بيئة التطوير.

رابط المشروع يكون عادةً بالشكل `https://<project-ref>.supabase.co`، وليس `*.supabase.com`.

تُدير Supabase كلمات المرور. يخزن جدول `profiles` البريد واسم العرض فقط، وتمنع سياسة RLS المستخدم من قراءة ملفات الآخرين.
خيار «تذكّرني على هذا الجهاز» يحفظ جلسة الدخول في المتصفح عند اختياره؛ لا يحفظ الموقع كلمة المرور.

## 2. إعداد الشات بوت

الدالة `functions/chat/index.ts` ترسل سؤال المستخدم وملخص العقارات إلى Gemini 3.5 Flash-Lite وتعرض رده في الشات. العقارات التجريبية تُرسل من الموقع إلى الدالة، لذلك لا تحتاج الدالة إلى قراءة جدول عقارات أو تغيير صلاحيات RLS له. تحتاج إلى مفتاح Gemini محفوظ كـ secret في مشروع Supabase، وليس في ملفات الموقع أو واجهة الشات. أضفه من **Project Settings → Edge Functions → Secrets** بالاسم `GEMINI_API_KEY`، أو باستخدام CLI:

```powershell
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase secrets set GEMINI_API_KEY=YOUR_GEMINI_API_KEY
supabase functions deploy chat
```

الدالة تتحقق من جلسة Supabase قبل طلب الرد من Gemini. يتطلب الشات تسجيل الدخول. لا تحفظ رسائل المحادثة، لكن نص السؤال وقائمة مختصرة بالعقارات تُرسل إلى Gemini لإنشاء الرد. لا تضع مفتاح Gemini في `script.js` أو `supabase-config.js`.

## 3. تشغيل الموقع

افتح الموقع عبر استضافة HTTPS أو خادم ويب محلي، وليس عبر `file://`. يجب أن تتطابق عناوين إعادة التوجيه في إعدادات Auth مع عنوان الموقع.

## 4. الإعلانات والمعاينات

يشغّل الترحيل الثاني جدولي `property_listings` و`property_appointments` ويطبّق سياسات RLS. نشر إعلان جديد يتطلب تسجيل الدخول، ويُربط الإعلان بحساب صاحبه. يستطيع أي زائر قراءة الإعلانات المنشورة، بينما لا يرى طلبات المعاينة إلا صاحب العقار والمستخدم الذي أرسل الطلب. التحديث المسموح لصاحب الإعلان يقتصر على قبول الطلب أو رفضه. يستخدم الترحيل دالة مشغّل لتعيين مالك العقار من سجل الإعلان والتحقق من أن الموعد في المستقبل، لذلك لا ترسل الواجهة `owner_id` بنفسها.

الإعلانات التجريبية الثابتة في `script.js` لا تملك حسابات فعلية، لذلك يظهر عليها تنبيه بأن حجز المعاينة متاح لإعلانات المستخدمين المنشورة فقط. تُحفظ المفضلة وسجل المشاهدات محليًا في المتصفح؛ أما طلبات المعاينة وإعلانات المستخدمين فتُحفظ في Supabase.
تحسب حاسبة العائد في صفحة التمويل دخل الإيجار السنوي والعائد الإجمالي والصافي بعد المصروفات التي يدخلها المستخدم، وتعرض مدة استرداد تقديرية من دون احتساب الضرائب أو الشغور أو تغير الأسعار.

## 5. الصفحات وتحميل البيانات

الموقع مقسّم إلى صفحات مستقلة: `index.html` للعقارات، و`property-details.html` لتفاصيل العقار المحدد، و`appointments.html` لطلبات المعاينة، و`financing.html` لحاسبة التمويل والعائد، إضافة إلى صفحات `about.html` و`reviews.html` و`contact.html`. تحمّل صفحة العقارات قائمة الإعلانات المنشورة؛ وصفحة التفاصيل تستعلم عن الإعلان المحدد فقط؛ وصفحة المواعيد لا تجلب بياناتها إلا للمستخدم المسجّل. بقية الصفحات لا تحمّل بيانات العقارات أو المواعيد. لا تُحمّل مكتبة Leaflet إلا عند فتح الخريطة. على الهواتف وأجهزة اللمس تظهر الخريطة فوق بطاقات العقارات، ويُعاد ضبط حجمها عند تغيير اتجاه الجهاز. تستخدم رسالة الترحيب الصوتية النطق المدمج في المتصفح؛ وعلى الهواتف تبدأ بعد أول لمسة بسبب قيود التشغيل التلقائي.

## 6. البحث والمساعد الصوتيان

يعمل البحث والأوامر الصوتية وإملاء أسئلة المساعد بعد ضغط المستخدم على زر الميكروفون، ويتطلبان متصفحًا يدعم Web Speech Recognition وإذن الميكروفون؛ استخدم HTTPS أو `localhost`. لا يخزن الموقع تسجيلات الميكروفون، لكن خدمة التعرف الصوتي التي يوفرها المتصفح قد تعالجها؛ لا تمْلِ كلمات المرور أو معلومات حساسة. ردود المساعد الصوتية اختيارية ويمكن إيقافها من زر السماعة. لا يستخدم الموقع بصمة الصوت لتسجيل الدخول أو إثبات الهوية لأنها قابلة للتقليد؛ تظل حماية الحساب عبر مصادقة Supabase المعتادة.
